Pillow - Python Imaging Library. May or may not already be installed in your version of Python; if not, install with:
```
pip install pillow
```

This program requires OpenSSL, which is installed by default on Mac and Linux but not on Windows. 
The easiest way to run the program is to use WSL, which runs the Linux shell in a Windows terminal.
If you do not have WSL installed, install with the following command in a Powershell terminal:
```
wsl --install
```
